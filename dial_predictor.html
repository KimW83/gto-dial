How prediction works

The app finds your most similar historical runs based on STD Correction Factor (within ±0.015) at the same track. It then takes a weighted average of their elapsed times — more recent runs and closer STD matches count more heavily.

If no runs exist within that window, it widens the search up to ±0.04. The confidence score reflects how many matching runs were found and how closely they match your current conditions.

Time of day is used as a secondary filter — if you select Morning/Midday/Afternoon, runs from the same period get a small boost in weighting. Flagged runs (unusual MPH suggesting a problem mid-pass) are automatically excluded from predictions.

STD Correction Factor

STD (Standard Day) correction normalises your run data to standard atmospheric conditions. A factor of 1.000 = perfect standard day. Above 1.000 = air is less dense, the car tends to run slower. Below 1.000 = denser air, faster runs.

The Bend records this as a 4-digit number (e.g. 1034 = 1.034). Sydney Dragway records it as a decimal. The app handles both formats automatically.

Manual STD calculator

On the Predict tab you can enter temperature, humidity, and barometric pressure to calculate an estimated STD correction factor automatically. This uses the standard ICAO atmosphere formula used in motorsport.

Data storage

All run data is stored in your browser's local storage. It stays on your device and is not sent anywhere. Use the Log Run tab to add new passes after each event. Your data will persist between sessions as long as you use the same browser.
